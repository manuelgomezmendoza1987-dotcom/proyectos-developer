El mundo de la programación web es el desarrollo de sitios y aplicaciones en internet, dividiéndose principalmente en Frontend
 (lo que el usuario ve, diseñola y experiencia) y Backend (la lógica del servidor y bases de datos), con roles Full Stack combinando
  ambos; utiliza lenguajes como HTML, CSS y JavaScript para interactuar con tecnologías como Python, PHP, o Java, creando desde
   páginas estáticas hasta aplicaciones complejas, siendo una disciplina fundamental 
   para la funcionalidad e interactividad en línea.
